Biogeme is open-source software designed for the maximum likelihood estimation of parametric models in general,
with a special emphasis on discrete choice models.

## Install
Biogeme requires Python >= 3.12 and can be installed [from PyPI](https://pypi.org/project/biogeme/).

`pip install biogeme`

Installing Biogeme from source can be done after cloning the repository with the following command executed in the 
root directory:

`pip install .`
